# 物語の表現ルール（2026-10-01）

元資料: Google ドキュメント「研修各ストーリー素案（更新用）」。アプリに載せる物語・アイテム・ステータスの言葉は、このルールに合わせる。元資料は変更しない。

## 決定事項（ユーザー確認済み）

| ルール | 理由 |
|---|---|
| 武器の表現は使わない（剣・盾・武器） | このゲームに戦闘は無い。物語の最終目的は「宝は自分の中にあると気づき、価値観とビジョンを持って仲間と歩み出すこと」 |
| 魔物・モンスターは残す | 戦う相手ではなく、迷いや誘惑のたとえとして出てくる（フェーズ12・15） |
| ステータスは戦闘の用語を言い換える（下表） | 体力（HP）・攻撃力などは戦闘ゲームの用語 |
| 第1章は、いまの地図に合わせて場所の言葉だけを置き換える | 地図の描き直しには時間がかかるため。詳細は `docs/story-chapter1-map-adaptation.md` |

## ステータス名（2026-10-01 ユーザー承認）

資料の「研修的ステータス」の説明に合わせた名前にする。成長の用語（経験値・レベル）と、戦闘を連想しない名前（知力・スキルポイント）は残す。

| 元の名前 | 新しい名前 | 資料の説明（要約） |
|---|---|---|
| 体力（HP） | 忍耐力 | 忍耐力・回復力・困難を乗り越える精神的タフさ |
| 魔力（MP） | 発想力 | 発想力・直観力・状況に応じた柔軟な対応 |
| 攻撃力 | 行動力 | 主体性・行動力・行動に移す力 |
| 防御力 | 安定力 | 精神的安定・自律性・感情コントロール・冷静さ |
| 生命力 | 継続力 | 意志力・継続力・信念に基づいて行動し続ける力 |
| 抵抗力 | しなやかさ | 困難耐性・柔軟性・ストレス耐性・否定への対応力 |
| 素早さ | 決断力 | 判断力・決断スピード・即時の行動 |
| 器用さ | 対話力 | コミュニケーション力・状況把握と変化への適応力 |
| 知力 | （残す） | 思考力・戦略的視点・相手の本質を見抜く力 |
| スキルポイント | （残す） | 問題解決力・応用力・知識と経験の蓄積 |
| 経験値 | （残す） | 自己成長・学びの実感 |
| レベル | （残す） | 人格・影響力の成熟度 |

注意: 元の説明では「体力」「生命力」「抵抗力」の中身が近い（回復力・継続力・困難耐性）。数値として表示するなら、違いが伝わる説明文を付けるか、統合を検討する。
