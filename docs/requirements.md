# 新ワールドマップ・学習体験 要件定義書

> **2026-10-01 改訂:** 章・目的地・報酬の構成（10章・10目的地・章ごとの報酬1個）は、`docs/story-structure.md`（3章・12か所・30フェーズ・30アイテム）に置き換えた。この文書のうち構成に関する記述は古い。地図の画風・表示操作・アクセシビリティなど構成に関係しない記述は有効。


> ステータス: 実装着手 — 2026-09-27、ユーザーの一括実装指示により10章案を採用。過去の検討案は経緯として保持。

## 目的

36街の密集したラベルと一様な見た目を改め、立体感があり進行方向を読み取りやすいRPG風の世界マップを作る。学習を終えると次の町が開く既存の流れを維持し、章の修了とキャラクターの成長・装備報酬を結びつける。

## 利用者と利用環境

- 主な利用者: 自己啓発教材を順に学ぶ人。PCブラウザ・スマートフォンブラウザを利用する。
- 管理者・教材編集者: 現状定義なし。専用編集画面は今回作らず、教材はアプリ内データとして管理する。
- 利用環境の確認状況: 現行アプリはReact/Vite、学習状況は端末内localStorageに保存。アカウント、バックエンド、端末間同期はない。

## 機能要件

| ID | 要件 |
|---|---|
| F-1 | 地図を新しいアイソメトリック風タイル構成に作り直し、草原・森・山岳・荒野・雪原・水辺の6地域を一本の道でつなぐ。 |
| F-2 | 36街を約10章・約10学習目的地に再編する候補を採る。町名は保留し、地図では章番号と章タイトルを使う。 |
| F-3 | 道筋・町・地形を使って次の進行先を理解できるようにする。マップ上を移動する操作キャラクターは置かない。 |
| F-4 | 現在地・修了済み・未解放を色だけに頼らず判別できる。未解放先の教材は開かない。修了済み教材は見返せる。 |
| F-5 | 章内の必須教材を完了すると修了証を表示し、次の目的地を解放して自動で次の章へ進む既存の学習導線を保つ。 |
| F-6 | 能力・ステータス表示を開くとキャラクターを表示する。マップ上には表示しない。学習進捗に応じて基礎姿が成長し、修了証ごとの装備報酬が外見に反映される。 |
| F-7 | 章ごとの教材を、理解・具体例・練習・自分の行動への置き換えを含む内容に再構成する。実生活での実践や自由記述は章修了の必須条件にしない。 |
| F-8 | PC・スマートフォンでマップ外の黒い余白を露出させない。タッチ・マウス・トラックパッドでの地図操作を画面サイズに合わせる。 |
| F-9 | 既存の学習記録を移行する場合、旧記録を消さず、何が引き継がれたかを説明する。 |

## 主要な体験の原則

- 目的地を見つけるために細かい文字を読ませない。進行状態は地形と建物に重ねる少数の記号で示す。
- 章の必須学習は一画面ずつ進め、途中で離れても同じ教材から再開できる。
- 選択問題は考え方を練習するために使い、人格評価や唯一の正解当てにしない。
- 行動記録・自由記述を設ける場合は任意とし、他人に共有しない。
- 章を終えると修了証・装備報酬・基礎姿の変化・次の町の解放を一連の達成として伝える。

## 非機能要件と合格ライン案

- 画面: PC 1440×900 / 1920×1080、スマートフォン縦 375×812、横 812×375で、章タイトルや進捗表示が重ならず操作できる。
- 地図の境界: 任意の許可されたパン・ズーム位置で、マップ外の黒い余白が見えない。主要な進行路と現在地は画面内に戻せる。
- 操作: タッチ、マウス、キーボードで目的地を選べる。進捗は色・アイコン・形状のうち二つ以上で区別する。
- 保存: 完了した教材と獲得アイテムはページ再読込後も残る。サーバー送信を行わない。
- パフォーマンス・容量: 未測定。代表区画と全マップの試作で実測し、実装前に合格値を定める。

## スコープ外

- キャラクターをマップ上で歩かせる機能。
- 町名の決定、住民の配置、オンラインランキング、アカウント、クラウド同期。
- 教材の自動生成、専用教材編集システム、行動の実行証明。
- 課金、広告、外部サービスへの進捗送信。

## 既存利用者への確認・移行方針案

現行保存キー `mind-seeker-learning-progress-v1` のJSONは読み取り専用で保持し、旧教材の再読機能は設けない。現行ローダーが有効と認識する連続完了ステージだけを旧完了として扱い、旧ステージIDを章順に割り当てた移行用コホートを使う。章完了は条件を満たす最長の連続章だけを引き継ぐ。途中教材の元データは旧キーに残るが、アプリ上の再開・再読は保証しない。新章の未完了分は章頭から開始し、この制約を移行時に一度案内する。

## 提案値つき未決事項

- 章数・町数: 10章・10町を作業上の基準案とする。最終承認と教材棚卸し後に固定し、必要なら±2章を再検討。承認前は他文書の10章詳細も提案値。
- 基礎姿の成長: 初期姿＋2章ごとの変化で計6段階。毎章は修了報酬アイテムで見た目を変える。
- 章内教材: 4〜6個を目安にする。すべての章で同数にはしない。
- マップ操作: PCは全体表示を初期値とし、拡大時だけドラッグ／トラックパッドでパン。スマートフォン縦は幅に合わせた縦スクロール、横は全体表示を基本とする。
- 報酬: 各章の修了証に一つの装備を結びつける。獲得品は自動装備し、後から所持品一覧で付け替えられる。
- 移行: 旧ステージ単位の完了記録を消去せず保管し、旧ステージ対応表に基づいて新章の完了を計算する。途中進捗は旧記録に残し、新章はその章の先頭から始める。
- 個人の振り返り: 既定では自由記述を保存しない。保存機能を加える場合も端末内のみ・本人のみ表示。
