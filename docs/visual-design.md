## 画面の考え方

大人が落ち着いて学べる冒険地図として、夜の藍色の外縁から、暖色の羊皮紙に収めたアイソメトリック地形へ視線を導く。情報の主役は一本道と次の目的地であり、細かな装飾や町名で学習順を競合させない。キャラクターは地図に出さず、能力パネルで成長と装備を見せる。

## コンポーネントとレイアウト

```
WorldMapPage
├─ AppHeader (ロゴ / 「能力と装備」 / 現在地へ)
├─ MapStage (地図の外側を見せないビューポート)
│  ├─ IsometricWorldSvg (1920 × 1080)
│  │  ├─ TerrainLayer (6地域、菱形セル、崖・水・小物)
│  │  ├─ RouteLayer (一本のS字路、地域ごとの材質)
│  │  ├─ LandmarkLayer (非操作の塔、橋、遺跡)
│  │  └─ SettlementArtLayer (10地点、6種の建築)
│  ├─ DestinationControls (地点ごとのHTML/SVG button、状態表示とラベル)
│  └─ MapControls (拡大、縮小、現在地へ)
├─ ChapterSheet (選択した地点の詳細。PC右側 / モバイル下部)
└─ StatusDrawer (能力、成長アバター、装備スロット、所持品)
```

PC はヘッダーを 64px、地図面を残りの画面高から 32px の余白で配置する。地図面の角丸は 24px、羊皮紙枠は 2px。詳細シートは地図右端に 360px 幅で重ね、選択した建物を覆わないよう左側の地点を選んだ時も右に固定する。シートが開いていない時の視野を基準の体験とする。

スマホ縦はヘッダー 56px、地図を画面幅いっぱいに表示し、地図カードの縦スクロールで 3 段のS字を読む。地点ボタンは 48px 以上、ラベルは最小 12px とし、ラベル同士は 12px 以上空ける。詳細は画面下から最大 72svh のボトムシートで開く。スマホ横は地図を全体表示し、シートを幅 320px 以下の右パネルにする。タップ・キーボードとも地点全体を選択でき、未解放地点は説明を返す。

## 地図座標と順路

論理キャンバスは `1920 × 1080`。各地点は最低 240px 程度離し、ラベル領域を建物の外に逃がす。順路は太さ 24px の明るい道と 8px の中心線で連続させ、先の地点だけに金の縁と「次の学び」を示す。

地域の境界には混合帯を入れ、森から山は木から岩へ、山から荒野は青灰から赤茶へ、雪から水辺は雪解け川へ切り替える。脇道に見える線は置かない。水面のきらめき、樹冠、岩、雪の面は菱形タイルの上に重ね、建物より淡くして主従を守る。

## 建築・進捗表現

6種の基本シルエットを再利用し、同じ形の町を連続させない。屋根の高さ、塔の有無、横幅、周辺小物で認識を作る。実装は外部画像を必要としない SVG の多角形・楕円・パスで始め、後から描き下ろし素材に置換できるグループ構造にする。

| 種別 | 輪郭 | 主な使用地点 |
|---|---|---|
| 風車小屋 | 低い石壁、三角屋根、羽根 | 01 |
| 学び舎 | 横長の丸屋根と本の窓 | 02 |
| 樹上塔 | 幹を通る高い円塔 | 03 |
| 橋の集落 | 木造小屋と短い吊り橋 | 04 |
| 峠の砦 | 段丘の石壁と旗 | 05 |
| 修道院 | 複数棟の石屋根、鐘楼 | 06 |
| 円形遺跡 | 崩れた石柱と火鉢 | 07 |
| 雪小屋 | 厚い屋根、煙、橙の窓 | 08 |
| 灯台 | 細い白塔と光 | 09 |
| 港町 | 高床市場、帆、桟橋 | 10 |

完了は緑の蝋印と道の暖色化、現在は金の外周リングと小さな方位星、未解放は彩度を 45% 下げた建物と鍵印で同時に表す。色だけで区別しない。現在地の控えめな発光は `prefers-reduced-motion` では停止する。

## 配色・文字・余白

| 用途 | 色 |
|---|---|
| ページ外縁 | `#17243A` |
| 夜空の補助 | `#243654` |
| 羊皮紙 | `#F5E6BF` |
| 羊皮紙の濃淡 | `#DFC58B` |
| 本文インク | `#2C241B` |
| 現在地・強調 | `#E9B44C` |
| 完了 | `#5D966B` |
| 未解放 | `#8A826F` |
| 草原 / 森 | `#88A95B` / `#3D6B4E` |
| 山 / 荒野 | `#788594` / `#A76B42` |
| 雪 / 水辺 | `#DDECF3` / `#4D91A3` |

フォントは既存のファミリーを優先し、見出しは 700、本文は 500。PC の章ラベルは 14px / 20px、番号は 11px の字間広め、詳細見出しは 24px。角丸はカード 16px、地図 24px、ラベル 10px。間隔は 4px 基準で 8 / 12 / 16 / 24 / 32px を使用する。

フォーカスは羊皮紙と区別できる `#1D4E89` の 3px 外側リング、最小コントラストを十分に取る。地図の文字は建物テクスチャ上に直接置かず、半透明でない羊皮紙ラベルに載せる。

## 能力パネルのアバター

アバターは約 220 × 290px の正面立ち絵。成長は初期を含め 6 段階で、0–1章は質素な旅装と控えめなひげ、2–3章で整った上着、4–5章で肩掛け、6–7章で旅人の意匠、8–9章で上質な外套、10章で落ち着いた指導者風の装いへ変える。人物の尊厳を損なう描写はしない。

各装備はアバター上の独立 SVG グループに重ねる。帽子、首飾り、肩、手、腰、背、胸、靴の8スロットを使い、10報酬のうち同スロット品は所持品から選択可能にする。初回獲得は空きスロットへ自動装備し、成長と装備を別レイヤーで保つ。

## 操作・アクセシビリティ

- 地図を拡大した時のパンは `MapStage` の表示範囲を越えない値にクランプする。通常時は地図の外側を描画しない。
- 地点は button として実装し、名称・章番号・進捗・未解放理由を `aria-label` に含める。Enter と Space で開く。
- 詳細・能力パネルは閉じるボタン、Escape、開いた元のボタンへのフォーカス復帰を備える。
- 重要な状態を通知する `aria-live` は、地点選択と章解放の短い文に限定する。
- 透明度だけで状態を示さず、鍵、蝋印、金の方位星、テキストを組み合わせる。

## 既存デザインとの整合

現行アプリにはタイトル画面、地図、教材、証書、能力パネルという大枠がある。新UIは React + CSS の既存構成を維持し、外部UIライブラリを導入しない。既存の木・石・羊皮紙のファンタジー素材の印象を、より低密度な羊皮紙パネルと藍色の背景へ整理する。固定座標の地図画像を直接操作する方式は、操作領域の44px保証とPC境界クランプの要件を満たしにくいため、SVG地図とHTML/SVG操作レイヤーを分ける。

## モックアップ

`docs/world-map-mockup.html` は外部画像なしの静的HTML/CSS/SVGモックアップである。`/gen-rich-image` スキルはこの環境にないため、Step 2.5 の代替手順に従いHTMLで作成した。実装担当はこの視覚密度・色・余白を基準に、実際のインタラクションを構築する。
