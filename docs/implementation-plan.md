## 実装の原則

- 仕様書と設計書の承認後に開始する。ユーザーは実装前にGPT-6 Astraへ切り替えることを希望している。実装着手前の引き継ぎ地点でその旨を伝える。
- 1回の作業を独立してレビューできる単位に分ける。進行中は選択肢をユーザーへ都度確認せず、承認済み仕様とこの計画に従う。
- コミット・プッシュは明示指示を待つ。公開・デプロイも明示指示を待つ。
- 現行データを上書きしない。旧v1形式は読み取り専用で保持する。旧教材の再読機能は提供しない。
- 実装開始条件として、10章案の最終承認、章順・教材単位・旧ステージ移行コホートを一意な表で確定する。

## セッション分割と完了条件

### 1. 教材・進捗の棚卸しとデータ契約

- 既存36ステージ・108教材・保存スキーマを照合し、10章案の教材素材参照表と進捗移行用コホートを別々に確定する。
- `chapterOrder`、`legacyStageIds`、`requiredUnitIds`、必須／任意、完了条件を実装可能な表にする。新規・横断教材は旧完了を付与しない。
- 完了条件: 全36旧IDに重複・欠落がなく、移行結果が最長連続完了章プレフィックスとなる。旧保存を変更しない検証ケースがある。

### 2. タイルアセットの小規模スパイク

- 草原直線、森カーブ、山岳橋、地域境界、代表建物1種を作る。
- 静的生成方式とブラウザ描画負荷を比較し、PC・縦横スマホで容量・ロード・継ぎ目を計測する。
- 完了条件: 選んだ描画方式、セル寸法、光源、画像形式、容量上限、失敗時の簡素化策を記録。

### 3. 地図レイヤーとレスポンシブカメラ

- タイル地形、一本道、6地域、10目的地をデータから描画する。
- 目的地ボタン、進捗状態、詳細パネルを地形と独立したレイヤーへ置く。
- PCの拡大パン制限、スマホ縦スクロール、横画面パン、地図外余白なしを実装する。
- 完了条件: 指定4サイズと回転・リサイズで全地点へ到達でき、黒い余白が見えない。

### 4. 章教材・修了・旧データ移行

- 新章IDと教材単位の進捗、章の再開、修了証、次章自動解放を実装する。
- Rootの初期化・v1保存effectより先に動く読み取り専用ブートストラップを追加する。最長の連続章プレフィックスだけを移行し、v2保存成功後に新UIを開始する。v1保存effectを除去または隔離する。
- 一度だけの移行案内を追加し、旧キーの改変・削除・書き戻しがないことを確認する。
- 完了条件: 新規利用、途中再開、既存完了者、移行失敗、再閲覧の各導線を確認。

### 5. キャラクター成長・装備報酬

- ステータスパネル内のキャラクター、6段階の基礎姿、章ごとの装備報酬、所持品一覧と付け替えを実装する。
- 報酬重複防止、保存・再読み込み、動きを減らす設定を確認する。
- 完了条件: 章修了から報酬獲得・装着・成長が一連で動き、再閲覧で重複しない。

### 6. 統合・品質確認とレビュー

- `npm run build` / `npm run lint` / `git diff --check` を実行する。
- PC 1440×900・1920×1080、スマホ縦375×812・横812×375で位置・文字・操作範囲を実測する。ブラウザテストランナー未導入のためユニットテストは追加・実行しない。
- 実行時正確性、設計、規約、可読性、画面品質をレビューし、指摘を修正後に再確認する。
- 完了条件: すべての必須導線が確認済み、未解決項目を記録、コミット・配布は未実行。

## リスクと退避ルール

| リスク | 対策・退避案 |
|---|---|
| 立体アセットの継ぎ目・容量・ロードが不適 | 小さな接続区画を先行試作。重い場合は装飾レイヤーを減らし、地面と道を圧縮して静的合成する |
| 10地点が小さくスマホで押せない | 縦画面では縦スクロールし、タップ領域を地面上の建物より広く確保する。必要なら二画面の地域別表示を代替案にする |
| 旧進捗が新章と意味的に一致しない | 旧記録を消さず、順序コホートと最長連続章だけを移行。途中教材は旧JSONに保持するが再読機能は提供せず、新教材は章頭から開始する |
| 報酬画像の数が増え制作負荷が高い | 共通スロット形状・地域素材差を再利用し、章固有の大きなシルエット変化を優先する |
| 開発中にスコープが膨張 | 学習導線、地図の視認性、進捗保護を最優先。任意の記録・演出・景観小物の順に後ろ倒し |

## 見積もりと律速要因

日数は素材制作手段・教材棚卸し・実機確認の可用性が不明のため未確定。実装計画承認後、地図スパイクと教材対応表の完了を基に楽観・悲観の両方を見積もる。遅延時は遠景の小物、追加アニメーション、任意の振り返りから削り、地図の道筋・教材完了・データ保護・キャラクターの成長報酬は維持する。
